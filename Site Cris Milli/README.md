# Site oficial da Cris Milli

Projeto pronto para publicar na Netlify, com:

- página oficial da campanha;
- formulário de Nome, WhatsApp e Cidade;
- envio automático dos cadastros para a planilha;
- redirecionamento para o grupo oficial do WhatsApp;
- página de Política de Privacidade;
- configuração responsiva para computador e celular.

## Como colocar no GitHub

1. Descompacte o arquivo ZIP.
2. Entre em [github.com](https://github.com) e crie um repositório novo.
3. Use o nome `cris-milli-oficial`.
4. Dentro do repositório, clique em **Add file → Upload files**.
5. Envie todos os arquivos e pastas que estão dentro de `cris-milli-netlify`.
6. Clique em **Commit changes**.

Importante: envie o conteúdo da pasta descompactada, não o arquivo ZIP.

## Como publicar na Netlify

1. Entre em [app.netlify.com](https://app.netlify.com).
2. Clique em **Add new project → Import an existing project**.
3. Escolha o GitHub e autorize o acesso.
4. Selecione o repositório `cris-milli-oficial`.
5. A Netlify reconhecerá o projeto automaticamente.
6. Confirme o comando de construção como `npm run build`.
7. Clique em **Deploy** ou **Publish**.

## Como mudar o endereço gratuito

Depois da publicação:

1. Abra o projeto na Netlify.
2. Entre em **Project configuration**.
3. Procure **Project details** ou **Change project name**.
4. Escolha um nome como `crismilli30180`, se estiver disponível.

O endereço ficará parecido com:

`https://crismilli30180.netlify.app`

## Atualizações futuras

Depois que o GitHub estiver conectado, qualquer alteração enviada ao repositório fará a Netlify publicar uma nova versão automaticamente.
